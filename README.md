# VK Bot — Календарь с AI

VK бот-календарь с напоминаниями и AI-ассистентом на базе Groq.

## Возможности

- Добавление событий с датой и временем
- Просмотр расписания: на завтра, на 3 дня, на месяц
- Напоминания за 3 часа до события
- AI-ассистент (Llama 3.3 70B) для ответов на сообщения

## Установка

```bash
git clone https://github.com/timatygecatti/-.git
cd -
python -m venv venv
venv\Scripts\activate   # Windows
pip install -r requirements.txt
```

## Настройка

Создайте файл `.env` по образцу `.env.example`:

```
VK_TOKEN=ваш_токен_сообщества
GROQ_API_KEY=ваш_ключ_groq
```

## Запуск

```bash
python bot.py
```

## Использование

| Команда | Описание |
|---------|----------|
| `3Д` | Расписание на 3 дня |
| `1М` | Расписание на месяц |
| `Р/З` | Расписание на завтра |
| `Добавить` | Добавить событие пошагово |
| `Название \| ДД.ММ.ГГГГ \| ЧЧ:ММ` | Быстрое добавление события |

Любое другое сообщение — AI ответит.
